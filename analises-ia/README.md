# 🧠 analises-ia/

Aqui ficam salvas as **análises de IA de cada campanha**, geradas pelo botão **"Salvar análise"** na página de detalhe da campanha no dashboard.

## O que aparece aqui

A cada análise salva, são gravados:

- **`<campanha>_<id>.md`** — a análise em formato legível (gargalo, diagnóstico e recomendações). **Este é o arquivo pra arrastar aqui no chat** quando quiser me mostrar.
- **`diagnosticos.json`** — todas as análises juntas em formato estruturado (uma por campanha, sempre a última).

## Como usar no nosso bate-papo

1. Abra esta pasta (`analises-ia/`) no explorador de arquivos.
2. Arraste o `.md` da campanha que quer discutir direto pra cá no chat.

## ⚠️ Privacidade

Os arquivos de análise **não são versionados no git** (contêm dados reais de cliente). Só este `README.md` é rastreado. Se a pasta aparecer **cinza/esmaecida** no VS Code, é só por causa do `.gitignore` — os arquivos continuam aqui e podem ser arrastados normalmente.
