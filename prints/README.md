# 🖼️ prints/

Pasta para você subir **screenshots do dashboard** e me mostrar mudanças, bugs ou como algo está aparecendo.

## Como usar

1. Tire o print do dashboard (Windows: `Win + Shift + S` para recortar, ou `PrtSc`).
2. Salve o arquivo aqui dentro (`prints/`).
3. Me avise no chat — ex.: *"olha o print `dashboard-funil.png`"* — que eu leio a imagem e analiso.

## Dicas

- **Nomes descritivos** ajudam: `dashboard-cards.png`, `bug-sync.png`, `funil-30d.png`.
- Formatos aceitos: `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`.
- Pode subir vários de uma vez.

## ⚠️ Privacidade

As imagens desta pasta **não são versionadas no git** (protegidas no `.gitignore`), porque os prints mostram **dados financeiros reais de cliente** (faturamento, ROAS, gastos). Ficam apenas na sua máquina. Só este `README.md` é rastreado.
